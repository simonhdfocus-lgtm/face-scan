# 网站素材人脸排查工具

上传一张参考图片 + 一个网站链接，自动扫描全站图片，找出匹配的素材及其所在页面。

## 两种识别模式

| 模式 | 用途 | 建议阈值 |
|---|---|---|
| 人脸识别 | 找含某个人的所有照片，认脸不认图 | 0.363 |
| 图片相似 | 找某张素材本身，支持无人像图 | 0.80 |
| 两者都查 | 同时比对 | 0.363 |

## 支持的站点类型

- **独立站 / 普通网站**：读取 sitemap，无 sitemap 时自动爬取站内链接
- **阿里国际站店铺**：调用店铺商品接口枚举全部在架商品

## 使用步骤

1. 上传参考图片
2. 填写要检索的网站域名
3. 选择识别模式
4. 点击开始扫描，实时查看进度与命中结果
5. 完成后导出 Excel 整改清单

## 说明

- 人脸识别使用 OpenCV YuNet + SFace 模型，图片相似组合 pHash / dHash / 颜色直方图 / ORB 特征点
- 所有计算在服务端完成，上传的图片仅用于本次比对
- 国际站商品详情长图需在本地配合浏览器登录态抓取，云端版本仅覆盖商品主图
